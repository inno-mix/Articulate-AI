# Phase 0 — Foundations

> **Milestone:** Q1 · **Status:** see `docs/tasks/README.md` · **Depends on:** nothing
> **For agentic workers:** follow `docs/guides/agent-workflow.md`. Tick subtasks as you go.

**Goal:** A monorepo where `make setup && make infra-up && make db-migrate && make seed && make dev`
starts the web app (3000), API (8000) and worker; the home page shows live API health; `make check`
runs lint, generated-client check and tests for both apps.

**Architecture:** Root Makefile + pnpm workspace (web) + uv project (api). FastAPI app factory
with settings, error envelope, logging, DB session, local-user dependency, health/me/settings
endpoints. Taskiq broker with an in-memory broker for tests. Next.js 16 app shell with TanStack
Query and an OpenAPI-generated client.

**Read before starting:** `docs/architecture/overview.md` (all), `docs/architecture/api-contract.md`
§1–2 (Health, Me), `docs/architecture/data-model.md` (Conventions, `users`, `profiles`,
`user_settings`), `docs/guides/local-development.md`, `docs/guides/coding-conventions.md`,
`docs/guides/testing-strategy.md` §1–3.

**Out of scope:** scenarios, sessions, LLM service (Phase 1); any UI beyond the shell and health badge.
